# WARAN Industries

Digital headquarters for WARAN Industries.

WARAN PRIMAL is the first operating division: AI-native software that turns operational bottlenecks into scalable systems. TECH, SCIENCES, CAPITAL, EXPLORATION and SPACE are planned capability layers — labelled as such, never fabricated as current operations.

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js 14 App Router + TypeScript
- Tailwind CSS
- React Three Fiber / Three.js for the cinematic homepage
- Content-driven divisions, missions, research and flywheel
- Contact API with validation, honeypot and rate limiting
